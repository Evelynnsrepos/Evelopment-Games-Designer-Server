## The first server

Evelopment Games Designer can now work through a server, so your team syncs even when nobody else is online.
Run it on your PC, a rented server or behind nginx. Needs Evelopment Games Designer 0.8.

- **Keys instead of accounts.** Make a key per person on the admin page (can view, or can edit) and send them the connect code.
- **Admin page with a setup wizard**: projects, keys, who is connected right now, backups, plugins, settings, privacy.
- **Four ways to be reached**: your own certificate (pinned by the app), behind nginx, your certificate files, or Let's Encrypt.
- **Plugins from the server**: install a plugin once on the server and everyone is offered it. The app always shows the plugin warning first.
- **Private by default**: no IP addresses stored, no tracking, nothing loaded from the internet. Templates for privacy notices and records of processing (German and English) are in `docs/operators`.
- **Tray icon** on Windows and macOS.
- Docker image, nginx example and a systemd unit in `packaging/`.

Downloads include SHA-256 checksums (`SHA256SUMS.txt`) and a software bill of materials (`egd-server.sbom.json`).
