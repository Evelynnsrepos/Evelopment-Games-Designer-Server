## The first server

Evelopment Games Designer can now work through a server, so your team syncs even when nobody else is online.
Run it on your PC, a rented server or behind nginx. Needs Evelopment Games Designer 0.8 or newer (0.28 for comment keys).

- **Keys instead of accounts.** Make a key per person on the admin page (can view, can comment, or can edit) and send them the connect code.
- **Comment keys** (app 0.28): the person sees everything but can only write review comments and statuses. The server checks every change on a copy of the project and drops anything else.
- **Admin page with a setup wizard**: projects, keys, who is connected right now, backups, plugins, settings, privacy.
- **Four ways to be reached**: your own certificate (pinned by the app), behind nginx, your certificate files, or Let's Encrypt.
- **Plugins from the server**: install a plugin once on the server and everyone is offered it. The app always shows the plugin warning first.
- **Private by default**: no IP addresses stored, no tracking, nothing loaded from the internet. Templates for privacy notices and records of processing (German and English) are in `docs/operators`.
- **Git sync in the background**: the server can push each project to a private Git repository every 10 minutes, on Sync now and when it stops. Push only, never force. Public repositories need the project's name typed in and show a red Public tag.
- **Runs on a normal PC**: `egd-server autostart on` starts it when someone connects (Linux) or at login (Windows, macOS), and it can stop itself when nobody has been connected for a while.
- **Everything from the terminal**: `egd-server <command>` does everything the admin page does, for headless servers (`egd-server --help`). `--no-admin-page` switches the web page off.
- **Asset Pool files** (app 0.28) sync and go into backups.
- **Tray icon** on Windows and macOS.
- Docker image, nginx example and a systemd unit in `packaging/`.

Downloads include SHA-256 checksums (`SHA256SUMS.txt`) and a software bill of materials (`egd-server.sbom.json`).
