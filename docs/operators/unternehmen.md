# Hinweise für Unternehmen / Notes for companies

> Vorlage, keine Rechtsberatung. / Template, not legal advice.

## Deutsch

**Beschäftigtendaten.** Wenn Beschäftigte den Server nutzen, verarbeiten Sie deren Daten im Beschäftigungsverhältnis
(§ 26 BDSG bzw. Art. 88 DSGVO). Informieren Sie die Beschäftigten mit den Datenschutzhinweisen.

**Betriebsrat.** Technische Einrichtungen, die geeignet sind, Verhalten oder Leistung zu überwachen, sind mitbestimmungspflichtig
(§ 87 Abs. 1 Nr. 6 BetrVG). Der Server ist deshalb so gebaut, dass er **keine** Aktivitätsdaten speichert:
keine Verbindungsprotokolle, keine Zeiten, keine Bearbeitungsverläufe pro Person, keine IP-Adressen.
„Gerade verbunden“ zeigt nur den aktuellen Zustand und wird nicht gespeichert. Projektinhalte enthalten aber,
wie in jeder Zusammenarbeit, wer was geschrieben hat, soweit Personen das selbst eintragen.
Sprechen Sie die Einführung mit dem Betriebsrat ab; diese Beschreibung kann als Grundlage dienen.

**Hoster.** Läuft der Server bei einem Hoster, ist dieser Auftragsverarbeiter: Schließen Sie einen Vertrag nach Art. 28 DSGVO (AVV) ab.
Bevorzugen Sie Rechenzentren in der EU.

**Eigene Relays.** Die App kann für die direkte Zusammenarbeit (ohne Server) öffentliche Relays verwenden.
Wer das nicht möchte, arbeitet nur über den eigenen Server.

**Rollen.** Die Person mit Zugang zur Admin-Seite kann alle Projekte lesen, Schlüssel widerrufen und Projekte schließen.
Legen Sie fest, wer das ist, und halten Sie es im Verzeichnis der Verarbeitungstätigkeiten fest.

## English

**Employee data.** If employees use the server, you process their data in the employment relationship
(national employment law, Art. 88 GDPR). Inform them with the privacy notice.

**Works council.** In Germany, technical systems able to monitor behaviour or performance need the works council's agreement
(§ 87(1) No. 6 BetrVG). The server is built to store **no** activity data: no connection logs, no times,
no per-person edit history, no IP addresses. "Connected now" shows only the current state and is not stored.
Project content does show who wrote what where people write that themselves, as in any collaboration.
Agree the introduction with the works council; this description can serve as a basis.

**Hoster.** A hosting provider is a processor: sign a data processing agreement (Art. 28 GDPR). Prefer data centres in the EU.

**Roles.** Whoever can use the admin page can read all projects, revoke keys and close projects.
Decide who that is and record it in your records of processing.
